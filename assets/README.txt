===========================================================================
 excel2mysql-cli —— Excel / ZIP / SQL 脚本 批量导入 MySQL（Windows 7 可用）
===========================================================================

这个包是命令行版，不需要安装 Python，也不需要图形界面：双击会弹出一个黑色命令
窗口。同一套推断与建表逻辑与图形版（需要 Windows 10 1809+）完全一致，建出来的
表结构相同。


一、开始之前（Windows 7 的前置条件）
---------------------------------------------------------------------------
1) 必须是 64 位系统，且已装 Service Pack 1（winver 里显示 Build 7601）。
2) 必须装好 UCRT（通用 C 运行时）补丁 KB2999226。
   没装时的症状：双击后弹"由于找不到 api-ms-win-crt-environment-l1-1-0.dll，
   无法继续执行代码"或"找不到指定的程序"。这不是本程序的 bug——进程根本没起来，
   所以看不到任何日志。检查办法（cmd 里执行）：
       dir C:\Windows\System32\ucrtbase.dll
       dism /online /get-packages | findstr 2999226
   任一报"找不到"就去装 KB2999226（Windows Update 一般已自动装好）。
3) 要能通过网络连到目标 MySQL（默认 127.0.0.1:3306，可在 conn.ini 里改）。


二、最省事的四条命令
---------------------------------------------------------------------------
在本目录按住 Shift 点右键 -> "在此处打开命令窗口"，然后：

  1) 先看会建成什么样，完全不碰数据库（强烈建议每次都先跑一遍）
       excel2mysql-cli.exe --dry-run D:\数据目录

  2) 只测连接通不通，顺便列出能导入的库
       excel2mysql-cli.exe --check

  3) 真正导入：目录或压缩包都行，并给全部表名加前缀
       excel2mysql-cli.exe D:\数据目录 --prefix ads_ --log 导入.log
       excel2mysql-cli.exe 数据包.zip --prefix ads_ --log 导入.log

  4) 把手头的 .sql 脚本执行到目标库
       excel2mysql-cli.exe D:\脚本目录 --run-sql --prefix ads_ --log 脚本.log

  用法与参数清单随时可以看：
       excel2mysql-cli.exe --help


三、连接配置（不用每次敲参数）
---------------------------------------------------------------------------
本目录自带一份 conn.ini，程序在没指定 -c 时会自动读它，改这个文件就行：

    [mysql]
    host = 127.0.0.1
    port = 3306
    user = root
    password =
    database =

密码建议不要写进文件，改用环境变量传，用完 set 清掉：

    set E2M_PASS=你的密码
    excel2mysql-cli.exe D:\数据目录 --prefix ads_

优先级：命令行参数 > 环境变量(E2M_HOST/E2M_PORT/E2M_USER/E2M_PASS/E2M_DB) > 配置文件。
数据库名(database)留空时，任何要写库的动作都会先报错停下，不会跑半截。
日志和报错里不会回显密码。

也可以显式指定别的配置文件： -c 别处的.ini


四、支持哪些输入
---------------------------------------------------------------------------
  .xlsx          常规 Excel（2007+）
  .xls           Excel 97-2003 老格式
  .zip           压缩包，自动展开包内的 Excel；嵌套 zip 不递归；带密码会报错
  .sql           脚本文件，只有加 --run-sql 才执行，不加时只登记并提醒一句
  目录           默认递归收集上面的文件；--no-recursive 只取该目录一层

表名与字段名规则（与图形版一致，自动完成）：
  · 文件名形如「水库基础信息（dim_reservoir_info）.xlsx」
        -> 表名取括号内英文 dim_reservoir_info，表注释取括号前中文
  · 没有有效括号时，表名由文件名汉字转拼音：水库基础信息 -> shui_ku_ji_chu_xin_xi
  · 字段名由中文表头逐音节转拼音、下划线分隔，超长自动降级为首字母
  · 类型与精度按全量数据推断（三位小数就出 DECIMAL(7,3)，不会圆成两位）
  · 自动挑主键；同一批里表名撞了自动加 _2、_3，不会互相覆盖
  · 含合并单元格的表直接拒绝导入，日志给具体位置（这类文件导进去必然错位）


五、常用开关
---------------------------------------------------------------------------
  --dry-run          只解析并打印建表语句，完全不连库
  --check            只连接并列出可导入的库名
  --run-sql          把 .sql 执行到目标库（每个文件一个事务）
  --prefix ads_      给全部表名加前缀。分隔用的下划线要自己写上；
                     已经以 ads_ 开头的表视为"已带该前缀"跳过，重复跑是幂等的
  --swap-prefix dim  换掉表名第一个下划线之前的首段：ods_t_order -> dim_t_order；
                     名里没有下划线的表不改，会在日志里逐条列出
  --drop-if-exists   建表前先 DROP TABLE IF EXISTS。会删掉目标库里的同名表和它的
                     数据，开启时日志会额外警告一句
  --batch N          每批插入行数，默认 500
  --log 文件名        把日志另存一份（UTF-8，追加写）。排查问题时整份发出去即可
  -q / --quiet       控制台只留警告、错误和汇总，日志文件仍记全量
  --no-recursive     目录只取一层
  --keep-temp        保留压缩包解压出的临时 Excel（默认处理完删除）
  -c / --config 文件名  指定别的配置文件（不给时自动读本目录的 conn.ini）
  --host / --port / --user / --password / --database（短写 -d）
                     临时覆盖连接信息里的某一项

日志一行读完整件事，行首是符号 + 大写标签，竖线分段：

  + [OK]   成功          例：+ [OK] 导入完成 | `t_order` 共 3 行
  ! [WARN] 提醒/跳过      例：! [WARN] 数据警告 | 共 2 个值无法转换，已按 NULL 写入
  x [ERROR] 失败         例：x [ERROR] 建表失败 | `t` | MySQL 错误码 1064：...
  - [INFO] 过程信息

数据库报错会展开成"异常类型 + MySQL 错误码 + 原文"，建表失败还会把那条语句原文
打出来。注意 CREATE/DROP/ALTER 属于 DDL，MySQL 会隐式提交，不会随事务回滚。

只要单独捞错误：
       findstr /C:"x [ERROR]" 导入.log


六、退出码（批处理里按码分流）
---------------------------------------------------------------------------
       0   全部成功
       1   用法或配置错误（参数冲突/非法、配置文件缺失、未指定目标库、没有可处理的文件）
       2   有输入文件解析失败（其余文件照常处理）
       3   无法连接 MySQL，或目标库不可用
       4   有表建表或导入失败（其余表照常处理）
       5   有 SQL 脚本执行失败（该文件已回滚，其余文件照常处理）
     130   按 Ctrl+C 中止

同时出现多种问题时取最严重的一档，所以批处理里从大到小判：

       if errorlevel 5 (echo 脚本失败) else if errorlevel 4 (echo 导入失败)


七、分发与拷贝
---------------------------------------------------------------------------
· 这个目录整体拷走（或压成 zip 发出去），解压后双击/运行 excel2mysql-cli.exe。
· exe 与同目录的 python38.dll、*.pyd、base_library.zip、conn.ini 必须放在一起，
  只拷 exe 跑不起来。
· 杀毒软件 / SmartScreen 可能对未签名的 exe 弹提示，选"仍要运行"即可。
· 目标机不需要装 Python。


八、跑不通时先查这几条
---------------------------------------------------------------------------
  · 双击没反应 / 弹"找不到 api-ms-win-crt-...dll"  -> 第一节，缺 SP1 或 UCRT
  · [连接失败] MySQL 错误码 2003                     -> 网络/端口不通，或服务端没允许该来源
  · [连接失败] MySQL 错误码 1045                     -> 用户名或口令不对
  · [连接失败] MySQL 错误码 1049                     -> 目标库不存在，先建库或用 --check 看有哪些库
  · [未指定目标库]                                    -> 改 conn.ini 的 database，或加 -d 库名
  · [合并单元格] 被拒绝导入                           -> 在 Excel 里取消合并区后重新处理
  · [数据警告] 已按 NULL 写入                         -> 该列里混了非数值内容，把列类型改成文本再导
  · 表建了但数据没进去（错误码 1062/1406 等）           -> 日志里有那条语句原文和错误码，按提示改表结构或数据
